 # Design Project — Shop Crane

  ## Overview

  **Course:** EDPT 501 – Engineering Design I
  **Project:** Shop Crane Design
  **No. of Members:** 4

  ---

  ## Introduction


  This is a complete mechanical engineering design project for a 1-ton shop 
  crane. The work spans from academic literature review → analytical
  force/stress calculations → full 3D CAD modelling in SolidWorks. The design
  follows standard mechanical engineering methodology: define loads, analyze
  forces, verify stresses with a safety factor, then model with standard steel
  sections.

  ---

  ## Project Goal
  
  Design a **shop crane** capable of lifting heavy loads, with the following
  input specifications:

  | Parameter              | Value          |
  |------------------------|----------------|
  | Lifting Capacity       | 1 Ton (1000 kg)|
  | Lifting Range          | 110 – 2000 mm  |
  | Height (horizontal)    | 1500 mm        |
  | Horizontal Length      | ~1700 mm       |
  | Wheel Diameter         | ~100 mm        |

  ---
  ## Folder Contents

  ### 1. `Project Requirements.pdf`
  The official project brief. Outlines:
  - Capacity range: 1–2 tons
  - Standard components: hydraulic cylinders, wheels, hollow steel sections
  - Required design sequence:
    1. Literature Review
    2. Define capacity & dimensions
    3. Motion Study
    4. Force Analysis
    5. Stress Calculations (SF ≥ 1.3)
    6. Select standard cross-sections
    7. 3D SolidWorks model
    8. 2D assembly drawing

  ---

  ### 2. `Literature Review.pdf` — Milestone 1.1
  Academic review covering:
  - **Crane types:** Tower, Mobile, Overhead/Gantry, Specialized
  - **Comparison table:** cost, capacity, mobility, power source
  - **Emerging tech:** IoT/AI smart cranes, automation, robotics
  - **Sustainability:** electric/hybrid cranes, regenerative braking
  - **Future trends:** autonomous cranes, big data analytics, modular urban
  designs
  
  ---

  ### 3. `Calculations.pdf` — Milestone 1
  Handwritten engineering calculations including:
  - Free Body Diagrams (FBD)
  - Equilibrium equations (ΣFx=0, ΣFy=0, ΣM=0)
  - Bending Moment Diagrams (BMD)
  - Stress analysis on critical cross-sections using hollow steel sections
  - Safety factor verified against steel yield strength
